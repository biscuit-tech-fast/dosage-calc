# OLD APPPPLE 生产计算器

两个静态网页工具，手机上扫码即用。

| 路径 | 工具 | 网址 |
|---|---|---|
| `/` | 除渣补液计算器 | https://biscuit-tech-fast.github.io/dosage-calc/ |
| `/tirage/` | 瓶内二次发酵计算器 | https://biscuit-tech-fast.github.io/dosage-calc/tirage/ |

## 加一株酵母

编辑 `tirage/strains.json`，加一条，Commit。刷新页面即生效，**不用重新构建**。
写错了页面会弹红条告诉你第几条、哪个字段有问题。

## 这是什么

静态站点（GitHub Pages），没有后端、没有追踪、不收集任何数据。
酵母参数来自厂商公开产品页，每条都注明来源。
